# AskMyLedger 🚀
> AI Financial Analyst & Interactive Dashboard powered by PayPal Sandbox, Groq Llama 3, and AG Grid.

Built for the **PayPal "Build What's Next" Global Hackathon**.

---

## 🌟 Overview
**AskMyLedger** bridges the gap between raw merchant transaction logs and plain-English financial insights. Instead of digging through complex multi-layered menus or writing manual SQL queries, merchants can chat naturally with their ledger (*"Show me all refunded subscriptions"* or *"Who owes pending payments?"*) and instantly view filtered, aggregated analytics inside a high-performance **AG Grid** interface.

---

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI, Pandas
* **AI Engine:** Groq API (High-speed LLM intent & JSON parser)
* **Payment Layer:** PayPal Developer Platform (Sandbox Orders & Transaction APIs with high-reliability mock fallback)
* **Frontend:** AG Grid Community, HTML5, Vanilla JavaScript, CSS3
